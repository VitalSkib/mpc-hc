# MPC-HC Fluent

A Windows x64 fork of [MPC-HC](https://github.com/clsid2/mpc-hc) with a video-first interface and live TV programme information.

**[Download for Windows](https://github.com/VitalSkib/mpc-hc/releases/latest)**

- Animated, translucent playback controls and titlebar over the video.
- An Acrylic playlist with smooth transitions.
- Adaptive controls for small windows, with native window dragging and resizing.
- Programme titles, schedules and local broadcast times for supported live TV streams.
- MPC-HC playback features, subtitles, keyboard shortcuts and settings.

## Install

Download the **x64-setup.exe** from the latest release and run it. The installer includes the player, codecs, languages and required components; no original MPC-HC installation is needed. It also upgrades an existing MPC-HC x64 installation.

Select **Use Fluent appearance** to enable the Fluent layout. Future releases are available through the player's update checker or GitHub release notifications.
